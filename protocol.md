## World / Object Mapping

When useful, explicitly record:

- World / research object
- Interface / observation boundary
- Cognition / interpretation boundary
- Data / recorded distinction
- Symbolic representation
- Dynamics
- Action
- View / model boundary

Do not infer a layer merely because a source uses similar terminology.

## Evidence Discipline

- Observation: what was directly observed
- Interpretation: what the observation is taken to mean
- Evidence: provenance-preserving observation/result relevant to claim evaluation
- Conclusion: evaluated knowledge update

Empty or unmappable fields are valid findings.
